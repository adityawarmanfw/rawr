Each focal length (14, 35, 85 mm) has these five options:

- **5600 Sun**: daylight.
- **2700 Bulb**: traditional incandescent light bulbs.
- **2700 LED**: newer LED lighting.
- **Sun-Bulb**: dual-illuminant daylight / traditional bulb.
- **Sun-LED**: dual-illuminant daylight / LED.

Choices follow the underlying camera across its lens modes and crops. They are
available without changing the active selection; Camera default stays selected
on fresh installations. User imports and selections are preserved on upgrade.
